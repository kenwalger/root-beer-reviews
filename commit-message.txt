Add URL field to root beer entries

Added an optional website URL field to root beer entries, allowing admins
to link to brand websites or product pages. The URL is displayed as a
clickable link on public root beer pages.

## Changes

### Model Updates
- Added `url: Optional[str]` field to `RootBeerBase` model (max_length=500)
- Added `url: Optional[str]` field to `RootBeerUpdate` model
- Field is optional and can be left empty

### Route Updates
- Added `url: Optional[str] = Form(None)` parameter to `create_rootbeer` route
- Added `url: Optional[str] = Form(None)` parameter to `update_rootbeer` route
- URL field is normalized (empty strings converted to None) in update route
- Updated route docstrings to document the new parameter

### Template Updates
- **Admin New Form**: Added URL input field with placeholder and helper text
- **Admin Edit Form**: Added URL input field with existing value display
- **Public View**: Added "Visit Website →" link below brand name (only displays if URL exists)
  - Link opens in new tab with `target="_blank"` and `rel="noopener noreferrer"` for security

### Import Script
- Updated `scripts/import_root_beers.py` to handle `url` field from JSON import files
- URLs can now be included in bulk import operations

## Features

- **Optional Field**: URL is not required, can be left empty
- **URL Validation**: Uses HTML5 `type="url"` input for basic validation
- **Public Display**: Shows as clickable link on public root beer pages
- **Import Support**: Can be included in JSON import files for bulk operations
- **Max Length**: 500 characters to accommodate long URLs

## Use Cases

- Link to brand websites
- Link to product pages
- Link to where to buy the root beer
- Link to manufacturer information
- Any relevant external resource

This enhancement makes it easier for users to find more information about
root beers and discover where to purchase them.
